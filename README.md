## عن المشروع

**AEIS** نظام يُدمج داخل النظام التعليمي للجامعة، يرصد مؤشرات التعثر الأكاديمي **قبل** أن يتحول إلى رسوب، ويقود الطالب خطوة بخطوة للعودة إلى المسار السليم.

بدلاً من أن يكتشف الطالب تعثره في نهاية الفصل، يرصده النظام مبكراً ويقدّم له خطة عملية.

## رحلة الطالب

اكتشاف التعثر ← الخطة العلاجية ← الالتزام ← التحسن ← العودة للمسار السليم

| المرحلة | ما يحدث |
|---|---|
| **١. الرصد** | تنبيه داخل صفحة المقررات عند انخفاض مؤشرات الأداء |
| **٢. التحليل** | تحديد نقاط الضعف بالموضوع، وأسباب التعثر |
| **٣. الخطة العلاجية** | خطة ٧ أيام: مهمة مراجعة + كويز قصير لكل يوم |
| **٤. المرشد الذكي** | شرح تكيّفي + ترشيح جهات الدعم داخل الجامعة |
| **٥. المتابعة** | قياس التحسن ومقارنة قبل / بعد |

## المزايا

**رصد مبكر** — تنبيه تلقائي مربوط بمؤشرات الأداء الفعلية: اختبارات، كويزات، واجبات، التزام.

**تحليل بالموضوع لا بالدرجة** — النظام لا يكتفي بقول "مستواك ٦٢٪"، بل يحدد أي موضوع بالضبط هو الأضعف.

**خطة علاجية قابلة للتنفيذ** — ٧ أيام مرتبة من الأضعف إلى الأقوى، كويز تقييمي بعد كل موضوع، إضافة الخطة إلى تقويم النظام، وتحميل ملف .ics لمزامنتها مع تقويم الجوال.

**مرشد ذكي تكيّفي** — ثلاثة أساليب شرح وثلاثة مستويات عمق تتغير حسب رد الطالب، ويعالج أخطاءه الفعلية في الكويزات لا الموضوع بشكل عام.

**من يساعدني؟** — ترشيح جهات دعم داخل الجامعة مع رسالة جاهزة للنسخ لكل جهة.
